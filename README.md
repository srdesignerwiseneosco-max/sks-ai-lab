# sks Ai Lab — channel website

Website for the **sks Ai Lab** YouTube channel: https://www.youtube.com/@TheSKSAILab

Static site (plain HTML/CSS/JS, no build step). Open `index.html` locally or serve with `python3 -m http.server`.
Live at https://srdesignerwiseneosco-max.github.io/sks-ai-lab/ (GitHub Pages, served from the `gh-pages` branch). Edit files on `main`; the workflow in `.github/workflows/pages.yml` mirrors `main` to `gh-pages` so the site republishes automatically.

## Placeholders to fill in
- Latest video cards (`#videos`): real titles, descriptions, thumbnails or embeds, per-video links
- About copy (`#about`): your own channel story / upload schedule
- `og:image`: optionally replace `og-image.svg` with a 1200×630 PNG for better social previews
